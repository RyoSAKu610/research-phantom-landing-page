# Online research: arXiv + open access

The six edited paper summaries remain available offline. Live search returns **unedited arXiv metadata** (English title, authors and abstract), not a generated summary or a recorded voiceover. The static `file://` edition has no same-origin API: it keeps the six papers and can link to the [arXiv website](https://arxiv.org/search/) for a live search.

## Run

Use Node 24. To develop, run `npm run dev` and open the local Vite URL. To serve a built edition with the API, run `npm run build` followed by `node server.mjs` (or `npm run start`) and open `http://127.0.0.1:4173/`. `PORT` and `HOST` can override the production defaults. A static hosting provider must run an equivalent API service; uploading `dist/index.html` alone cannot enable the same-origin endpoints.

Optional: set `UNPAYWALL_EMAIL` to a real contact address in the **server environment**, e.g. `UNPAYWALL_EMAIL="$YOUR_REAL_EMAIL" node server.mjs` after setting that variable to your address. `you@example.org`, `test@example.com` and other reserved example-domain addresses are placeholders: Unpaywall rejects them, and this server reports Unpaywall as unconfigured for them. Do not place a contact email in a `VITE_` variable or the HTML. Without a real server email, a visitor may supply their own real contact email to the OA request; the server uses it for that Unpaywall request only, without persisting or logging the email. Otherwise the article's canonical arXiv original and PDF links remain clickable beside the OA explanation, including for papers without a published DOI or with an arXiv DataCite DOI. `GET /api/research/status` returns `{ "arxiv": true, "unpaywall": false }` when no usable server email is configured. This is capability status, not an upstream availability probe.

## API contract

- `GET /api/research/arxiv?q=keyword&sort=relevance` searches the official [arXiv API](https://info.arxiv.org/help/api/user-manual.html). `sort=submittedDate` is also supported. Query length is 2–120 characters; each response has at most ten normalized papers. The API is fetched server-side because browser CORS availability is not guaranteed. Following [arXiv API terms](https://info.arxiv.org/help/api/tou.html), only one upstream connection is active at a time, request starts are at least three seconds apart, and each successful query/sort result stays cached in memory for 24 hours. The cache admits up to 128 distinct unexpired queries (including queued ones); when full, a new unique query receives HTTP 429 until a slot expires, while existing cached queries continue to work. Cache contents reset when the server restarts. Failure returns a safe JSON error and no synthetic papers.
- `POST /api/research/oa` with JSON `{ "doi": "10.1145/1234567" }` checks the [Unpaywall v2 API](https://unpaywall.org/products/api). If no server email is configured, include an optional `email` field containing your real contact address. Responses are `{ "status": "open" | "closed" | "unknown" | "unconfigured", "url"?: string, "license"?: string, "source"?: string }`. A real contact email is required by Unpaywall; the server email takes precedence. Invalid requests return JSON errors; timeout, rate limiting, unsupported DOI and uncertain data return `unknown`. OA responses are bounded and cached by DOI for one hour (uncertain responses for one minute). A `10.48550/...` arXiv DOI is registered with DataCite and is not submitted to Unpaywall: use its arXiv link to read the paper instead. Other syntactically valid DOIs may also be absent from Unpaywall; registry membership is not inferred from the prefix alone.
- `GET /api/research/status` reports whether the local proxy is mounted and whether a valid server-side Unpaywall email is configured. It does not reveal the email.

All live metadata and OA links are external data. Display titles and abstracts as text, and open outbound links with `rel="noopener noreferrer"`. An `open` OA status is only returned when Unpaywall reports OA and supplies a validated HTTPS public link; otherwise show `unknown`. The canonical arXiv PDF and abstract links remain available regardless of OA status.
